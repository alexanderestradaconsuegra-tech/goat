# GOAT League Admin

Panel privado recuperado del último despliegue GOAT válido en Vercel.

Incluye autenticación mediante Supabase Auth y módulos para inscripciones, pagos, equipos, jugadores, partidos, galería, configuración y delegados.

## Desarrollo local

Sirve esta carpeta como sitio estático. Para desplegarla en Vercel, configura `admin/` como Root Directory.
